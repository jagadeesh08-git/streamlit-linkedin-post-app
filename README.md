# 🚀 LinkedIn Humanized Post Generator

A Streamlit-based web application that generates human-like LinkedIn posts with hashtags and banner images automatically.

---

## 📌 Features
- ✍️ Generates professional LinkedIn posts from any topic  
- 🏷️ Automatically creates relevant hashtags  
- 🖼️ Randomly selects LinkedIn-style banner images  
- ⬇️ Download the generated image for posting  
- ⚡ Simple and interactive Streamlit UI  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  
- Requests  
- Unsplash Images
